The AKSARA icon is cropped from the central application-icon artwork in the
user-supplied `AKSARA_UI_Component_Pack/02_logo_icon.png`. The component boards
are design references; all interactive controls are native Gradio components.

`aksara.css` contains the responsive navy, teal and gold theme. Cinzel, Inter
and Cormorant Garamond are requested from Google Fonts, with local system font
fallbacks. The icon is embedded in the HTML so it works under the Space's URL
without exposing additional filesystem paths.
